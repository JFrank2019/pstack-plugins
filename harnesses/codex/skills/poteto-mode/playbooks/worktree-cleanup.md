### Worktree and simulator cleanup

1. Snapshot and audit. Record `df -h /`, then run `scripts/worktree-audit.sh [-b <pr-base-ref>] [repo-path]` (principle-build-the-lever). Without `-b` it checks `MERGED` against `origin/HEAD`, so pass `-b origin/<branch>` when PRs target another branch. It reads paths from `git worktree list`, never hand-typed, since a hand-typed path misses worktrees the tool registered elsewhere (principle-encode-lessons-in-structure). It classifies each worktree by size, age, merge state, uncommitted work, PR state, and the newest session that touched it, then suggests a bucket. The session rollout scan is slow, so spawn a subagent to run it.
2. The bucket is advice, not permission. The sessions in use now are the real artifact (principle-prove-it-works). Ask the user which sessions and worktrees are in use, and cross-check every candidate. The lever has marked `safe` a worktree the user was still using, so the user's list wins.
3. Verify usage before deleting. For every `verify-recent-chat` row, or anything you doubt, fan subagents out to read the matching rollout files under `$CODEX_HOME/sessions/` and report whether the session is still running and which worktrees it touches (principle-guard-the-context-window, rollouts are bulk). A running session spawns arena and repro trees into sibling worktrees via subagents, and those are in use even when the session's first prompt never names them. Pick each subagent's reasoning effort for the job, per the Subagents section. Spawn in waves per free subagent slots.
4. Pause on irreversible loss. `wip:N` is N tracked uncommitted edits. Show the diff and get a decision first, since removing a clean worktree is recoverable from its branch but uncommitted work is gone. `scratch:N` is untracked throwaway, safe to drop, but name the files. Per Autonomy, clean and merged and not-in-use proceeds. `wip` and in-use pause.
5. Prune the confirmed set. Per path, `git worktree remove --force <path>` with `sandbox_permissions: "require_escalated"` when the sandbox blocks `.git` writes. If the dir survives on ignored build artifacts, delete it with `rm -r <path>` (Codex refuses `rm -f` and `rm -rf`), then `git worktree prune`. Branch refs survive, so no commits are lost. Confirm with `df -h /` and re-list.
6. Simulators and other reclaimers. Simulators are usually the next-biggest win. `xcrun simctl --set testing delete all` (XCTestDevices clones), `xcrun simctl delete unavailable`, and `xcrun simctl runtime list` then `runtime delete <id>` for old runtimes. More when needed: Xcode `DerivedData` and `iOS DeviceSupport`, package caches (pnpm, uv, brew, yarn). Clear only caches the user has not said to keep.

This is the one playbook that deletes user state with no code review to catch a slip, so the gates above are the review.

**Reply:** `df -h /` before and after with space reclaimed, the worktrees pruned, and a one-line reason for each held back (in use by which session, or uncommitted work).
